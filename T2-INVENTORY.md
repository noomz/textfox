# T2 selector and variable inventory

This is a working ledger, not a support claim. Each group lists syntax in the checkout, evidence, and remaining states. `tools/firefox-chrome/inventory-css.py` produces the complete syntactic starting list. Rules in shared `overwrites.css` and `icons.css` must also be accounted for in their component groups.

Unless noted otherwise, source links use Firefox `FIREFOX_159_0_RELEASE` commit `9a2dc53c369c7ae5172018b35988e1d2ffeff402`. Live evidence in `NOVA-PORT.md` uses Linux Firefox 159.0 build `20261022150525`; the tag-to-build correspondence has not been established. A source match is not a live match, and a computed style is not a painted result.

## Shared icon scope

`chrome/icons.css` has 241 syntactic rule records in the current generator output. Grouping each record by its first enclosing media rule yields 128 under `shyfox.enable.context.menu.icons`, 23 under `shyfox.enable.ext.mono.context.icons`, 13 under `shyfox.enable.ext.mono.toolbar.icons`, and 77 without an enclosing media rule. Counts include nested rules and do not count distinct DOM targets. Conditional extension rules may need disposable extensions or representative fixtures to reach their states; absence of such an extension in a default profile is not evidence of a stale selector. `check-context-icon-source.py` found 83 of 89 simple candidate IDs from context-menu-nested icon rules in tagged Firefox `browser-context.inc.xhtml`; six were absent from that one file. Its live-ID join finds those same 83 candidates present and 11 visible in each sampled link-menu profile; all 11 computed `background-image: none` with the icon preference both off and on. Page, input, password, local-image, selected-text, paused-video, playing/muted-video, paused-audio, playing/muted-audio, and generated-PDF editor menus expose 9, 8, 9, 7, 7, 12, 12, 8, 8, and 14 candidate IDs with visible geometry, respectively; together with the link fixture, 54 distinct candidates are visible in sampled states. A synthetic password field's Reveal Password command toggles Firefox's `revealPassword` state and menu checkmark in both Nova states. All computed no background image, and counts include disabled items. Video and silent audio fixtures also exercise Play, Mute, Unmute, and Pause via pointer or keyboard and verify the resulting states. These are ID-level observations, not complete selector or full-source matches. The simple-ID join excludes the bare type selector `context-openlinkincontainertab`; a real container-tab probe confirms its visible target is a `menuitem` with that ID, not a matching element type. A modern-query intervention with the original selector list fails to style that item, while an ID-selector control applies an icon when enabled. Tagged Firefox markup defines `#context-pdfjs-select-all`, while textfox targets `#context-pdfjs-selectall`; the live link menu contains only the current ID, hidden in that fixture. The probe's generated-PDF editor fixture opens and activates the visible current item in both Nova states; the icon remains absent in sampled themed profiles. For `#placesContext`, a separate tagged-source and live join accounts for 27 simple IDs, including escaped colons: 26 occur in the tagged Places markup; all 27 were present in the live bookmark and folder menus; 14 bookmark and 12 folder candidates had visible geometry with no computed background image. Their union is 18 IDs. A pointer-activated folder command opened its local child in all sampled profiles. `probe-download-icons.py` also opens the actual completed-download panel menu: five targeted items have visible geometry and computed no background image in four Nova/preference combinations; a modern-query intervention applies the Show icon, and Remove From History removes only the disposable entry. History, other download states, and painted icon states remain unverified. No icon group is fully audited yet. `probe-context-icon.py` verifies a real link context-menu item and finds all three legacy icon preference media queries inactive even when enabled in both Nova states. Modern queries follow the effective preference values, and a temporary user-origin intervention applies the link icon. `probe-extension-icon.py` exercises browser-action and link-context targets using a temporary fixture extension with the uBlock selector's ID; modern-query controls apply the theme icon in sampled profiles. Other extension icon targets remain untested. `probe-panel-colors.py` finds 16 top-level app-menu targets with non-`none` computed image URLs in eight samples and loads those URLs with a missing-resource negative control. Matching, rendering, and interaction for other targets remain open.
