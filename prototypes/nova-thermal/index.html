Try an unsigned theme

Save a package, then open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select the file. If your browser tries to install the link directly, use Save Link As instead. The temporary theme is removed when Firefox restarts. Permanent installation in Firefox Release requires a Mozilla-signed package; these downloads are unsigned.

Textfox hides Firefox theme artwork by default. To show the Halo behind the window, set --tf-theme-images: 1; inside your existing :root rule in chrome/config.css and restart Firefox.

Optional: animated Textfox preset

For an existing Textfox installation, export the exact palette, background style, playback setting, and UI choice from the preview instead.

Install or remove the preset
  1. In Firefox, open about:support and open your profile folder.
  2. Save the downloaded file as chrome/thermal-atlas.css.
  3. Add the line below at the top of chrome/config.css, before other rules. Create the file if it doesn’t exist; keep any existing settings.
@import url("thermal-atlas.css");

Fully quit and reopen Firefox. To undo, remove the import and restart. These steps are for a writable Textfox profile, not a Nix-managed config. The preset doesn’t switch your tab layout.
